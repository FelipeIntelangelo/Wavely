# Reglas de Proyecto: Podcast UTN

## Comportamiento del Agente
- **NO COMPILAR NI EJECUTAR EL FRONTEND**: Hay problemas de dependencia con @angular/cdk. Nunca intentes correr comandos de compilación o ejecución de frontend (como npm run build o ng build) de manera automática. Realiza las modificaciones y asume que el usuario compilará por su cuenta.
